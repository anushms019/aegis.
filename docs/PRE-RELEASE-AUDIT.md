# Pre-release audit (Phase 0)

Read-only audit performed before any code change, per the release checklist.
Every row states what was checked, the exact evidence, and whether the claimed
problem was reproduced. Nothing in this file was fixed here — findings are
carried into the phase tasks (P1-x, P2-x, P3-x).

Legend — Severity: **Critical** = crash / data exposure; **High** = honesty or
security-default violation a reviewer will hit; **Medium**; **Low**; **Info**.
Verdict: **confirmed** = reproduced here; **not reproduced** = checked, claim
did not hold; **clean** = checked, nothing wrong.

Repro helpers added with this audit: `node scripts/audit-crash-each.js` (fresh
server per malformed input, prints SURVIVED/CRASHED) and
`node scripts/audit-signals.js <port>` (which ordinary requests get flagged).
